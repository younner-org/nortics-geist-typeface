# Licensing, in plain language

This page explains the licenses of the project. It is a summary to help you; the license texts ([`OFL.txt`](../OFL.txt) and [`licenses/MIT.txt`](../licenses/MIT.txt)) are what legally applies. It is not legal advice.

## What is under which license

| What | License | Where |
| --- | --- | --- |
| The **fonts**: `.ttf` and `.woff2` | **SIL Open Font License 1.1** | `fonts/`, text in [`OFL.txt`](../OFL.txt) |
| Build and QA scripts, web files (`webfonts.css`, `specimen.html`), documentation, images | **MIT** | `source/`, `web/`, `docs/`, root documents, text in [`licenses/MIT.txt`](../licenses/MIT.txt) |

The font metadata (name table) of every font states the OFL, so the license travels with the file.

## What you can do with the fonts (OFL 1.1)

You may, free of charge:

- **use them for anything**, personal or commercial: print, web, apps, video, games, logos, documents, products;
- **embed them** in documents, apps and websites;
- **install and share** them with your team or clients, as long as the copyright notice and the license come along (the `OFL.txt` file, or the metadata inside the font);
- **bundle them** with software and even sell that software;
- **study, modify and redistribute** them, including your own derivative fonts.

You do **not** need to credit the fonts when you use them to create content (a website, a poster, an app interface). Crediting is welcome but optional.

## What you must do

- **Keep the copyright notice and the license** with every copy of the fonts you redistribute.
- **Release modified versions under the OFL** too (the license is "copyleft" for the font software).
- **Do not use a Reserved Font Name** in a modified version. This project declares none; if you create a derivative, give it your own name rather than implying it is this project.
- **Do not use the names of the copyright holders or authors to promote or endorse** a modified version without their written permission (acknowledging where it comes from is fine).

## What you cannot do

- **Sell the fonts by themselves** (a font file or a pack of font files offered as the product). Bundling them with software, or using them in something you sell, is fine.
- Remove the license or the copyright notices.

## About the name "Geist"

*Geist* is the name Vercel uses for its typeface. Nortics Geist is an **independent adaptation**, published under the license that Vercel chose for the original. It is not affiliated with, endorsed by or sponsored by Vercel or basement.studio, and their names appear only to acknowledge the origin of the fonts.

The code in `source/`, the web files and the documentation can be used, copied and modified freely, including commercially, provided the MIT notice is kept. They are separate from the fonts: running the scripts on the upstream fonts produces font software that stays under the OFL.
