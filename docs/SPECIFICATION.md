Naming follows the RIBBI rule: only `Regular` and `Bold` use the bare family name in nameID 1; every other weight appends its style name to nameID 1 and sets nameID 2 to `Regular`. nameID 16/17 always carry the family and the style, which is what modern applications use to group the weights. The four families have different names, so they can be installed together and alongside the original Geist without conflicts.

- Units per em: **1000**. Vertical metrics are identical in `hhea` and OS/2 typo (ascender 1111, descender -225, line gap 0), `USE_TYPO_METRICS` (fsSelection bit 7) is set, so the default line height is 1.336 em in every application. `usWinAscent/usWinDescent` are computed per font from the real glyph extents so nothing is clipped.
- Spacing: every advance width is 20 units (0.020 em) narrower than in Geist; for the Mono families the cell is **580** units instead of 600.
- Underline (Regular): sans position -100, thickness 50; mono position -100, thickness 50 (inherited from Geist).

- Sans: space advance 230, `n` advance 561, `H` advance 693.
- Mono: advance widths present in the glyph set (excluding ligature glyphs): [480, 580]. Letters, digits and punctuation use the 580 cell; a small group of symbols inherited from Geist Mono is 480 wide.
- `post.isFixedPitch`: sans = 0, mono = 1.

## 5. File format

- Outlines: TrueType (`glyf`), quadratic Bezier, **unhinted** (all glyph programs removed; the `gasp` table asks for grayscale smoothing). Tables of the sans Regular: `GDEF, GPOS, GSUB, GlyphOrder, OS/2, STAT, cmap, gasp, glyf, head, hhea, hmtx, loca, maxp, meta, name, post, prep`.
- Distribution formats: `.ttf` (desktop) and `.woff2` (web, Brotli) with identical content.
- Static fonts only: **no variable font and no italics** are provided.
- Overlaps are removed in every glyph (no overlapping contours).
